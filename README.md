# TrueWaveites - Modern B2B Demand Generation Website

A cutting-edge React/Vite application showcasing TrueWaveites' B2B demand generation services with modern design, animations, and lead generation capabilities.

## 🚀 Features

### **Frontend Excellence**
- **React 18+ with Vite** - Lightning-fast development and builds
- **Framer Motion** - Smooth animations and micro-interactions
- **Tailwind CSS** - Utility-first styling with custom design system
- **Dark/Light Theme** - Advanced theme switching with system detection
- **Responsive Design** - Mobile-first approach for all devices

### **Business Features**
- **Hero Section** - Compelling value proposition with animated stats
- **Service Showcase** - Interactive service tabs with detailed information
- **Value Propositions** - Clear differentiation points
- **Testimonials** - Client success stories and social proof
- **Lead Generation** - Multi-step contact forms with validation
- **Contact Information** - Global office locations and business hours

### **Technical Highlights**
- **Component Architecture** - Modular, reusable React components
- **Performance Optimized** - Code splitting and lazy loading
- **SEO Ready** - Semantic HTML and meta tags
- **Accessibility** - WCAG compliance considerations
- **Modern Animations** - Smooth transitions and hover effects

## 🛠️ Technology Stack

### **Frontend**
- **React 18.2.0** - Modern component framework
- **Vite 4.1.0** - Fast build tool and dev server
- **Tailwind CSS 3.2.7** - Utility-first CSS framework
- **Framer Motion 10.0.1** - Animation library
- **Heroicons React 2.0.16** - Icon library

### **Development Tools**
- **PostCSS** - CSS processing
- **Autoprefixer** - Browser compatibility
- **ESLint** - Code quality and consistency

## 📦 Installation

### Prerequisites
- Node.js 16+ 
- npm or yarn package manager

### Setup Instructions

1. **Clone or Navigate to Project**
   ```bash
   cd truewaveites-new
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

4. **Open in Browser**
   Navigate to `http://localhost:5173`

## 🔧 Customization

### **Theme Colors**
Edit `tailwind.config.js` to modify:
- Primary, secondary, and accent colors
- Custom gradients
- Animation keyframes

### **Content Updates**
- **Hero Section**: Modify `Hero.jsx`
- **Services**: Update `Services.jsx` data
- **Testimonials**: Edit `Testimonials.jsx`
- **Contact Info**: Update `Contact.jsx`

### **Adding New Sections**
1. Create component in `src/components/`
2. Import in `App.jsx`
3. Add to main layout
